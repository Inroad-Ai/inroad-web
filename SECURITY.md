# Security Policy

Report a vulnerability privately through this repo's **Security** tab:
<https://github.com/Inroad-Ai/inroad-web/security/advisories/new>. Don't open
a public issue, pull request or discussion for it.

The full policy (response times, scope, and what matters most) lives in
`inroad-api` and covers every `Inroad-Ai` repo:
<https://github.com/Inroad-Ai/inroad-api/security/policy>.
