# api-client

Typed client for the FastAPI backend, generated from its OpenAPI schema.

- `schema.d.ts` - generated by [`openapi-typescript`](https://openapi-ts.dev/). Do not hand-edit; it is overwritten every time the generator runs.
- `client.ts` - hand-written. A thin [`openapi-fetch`](https://openapi-ts.dev/openapi-fetch/) wrapper typed against `schema.d.ts`, exposing one function per backend call (`fetchResearch`, `fetchHistory`) plus the shared `ApiError`. This is the only file in this folder meant to be edited.

## Regenerating `schema.d.ts`

1. Start the backend: `cd ../inroad-api && uvicorn app.main:app --reload`
2. From `inroad-web`, run:

   ```
   npm run generate-api-client
   ```

   This points `openapi-typescript` at `NEXT_PUBLIC_API_URL` (or `http://127.0.0.1:8000` if unset) and rewrites `schema.d.ts`.

Do this any time a backend route, request param, or response model changes. If `client.ts` no longer type-checks after regenerating, that's the signal a route's shape changed underneath it - fix the call site, don't work around it with a manual `fetch()`.
